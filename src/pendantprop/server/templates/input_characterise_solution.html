Solution Characterisation

Perform automated dilution series and surface tension measurements. The system will:

  • Create serial dilutions from the parent sample using the specified solvent
  • Measure dynamic surface tension at each concentration
  • Generate concentration-dependent surface tension plots
  • Save all results to the output folder with your experiment tag

Sample Info Requirements:

  • Required columns: well ID, sample ID, solvent
  • Solvent specification: Must specify which solvent to use for dilutions (e.g., "water", "ethanol")
  • Well ID format: Match the container names from your layout (e.g., "7A1" for position A1 in container 7)
  • One row per parent sample: Each sample will be automatically diluted according to settings

Critical:

  • Parent sample concentration: Ensure the parent sample in layout.csv is labeled with the correct concentration. The dilution series concentrations are calculated from this value, so errors here will propagate to results.csv.
  • Solvent location: Make sure the specified solvent container is present in the deck layout and has sufficient volume for all dilutions.
