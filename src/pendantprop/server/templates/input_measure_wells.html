Measure Wells Protocol

Measure dynamic surface tension for multiple samples. The system will:

  • Pick up sample from each specified well
  • Form a pendant drop and capture images over time
  • Analyze droplet geometry to calculate surface tension
  • Clean the needle after each measurement (ethanol wash → water wash → trash)
  • Save results and generate plots organized by sample ID

Sample Info Requirements:

  • Required columns: well ID, sample ID
  • Well ID: Must match container names in layout.csv (e.g., "8A1", "8B2")
  • Concentration (optional): If concentration data is needed in results, include it in The layout.csv file.
  • One row per well: Each well will be measured sequentially

Critical - Washing Requirements:

  • Automated cleaning sequence: After each measurement, the needle is automatically cleaned:
    1. Ethanol wash - removes sticky surfactants and sample residues
    2. Water wash - rinses away ethanol
    3. Trash - disposes of wash waste
  • Sufficient supplies: Ensure your deck layout includes containers with adequate volumes:
    • ethanol_wash - for removing surfactants
    • water_wash - for ethanol removal
    • trash - for waste disposal
  • See example: Check config/layouts/layout.csv for proper naming and positioning of wash containers.
