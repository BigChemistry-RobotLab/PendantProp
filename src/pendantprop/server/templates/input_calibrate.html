Calibrate

Enter the well ID containing water for calibration

Calibration Process:

  • Purpose: Calibrates the camera by measuring the scale (mm/px) from a water droplet
  • Requirements: Ensure the specified well contains pure, distilled water at room temperature
  • Process: The system will:
    • Pick up water from the specified well
    • Form a pendant drop at the drop stage
    • Capture images and analyze droplet geometry
    • Calculate the scale factor (mm/pixel) using known water properties
    • Measure over a calibration period to get an average value
  • Output: The measured scale will be logged. Update the scale parameter in settings to apply the calibration
  • Duration: Calibration typically takes ~60 seconds

Note: Make sure the needle is clean and the drop stage is properly positioned before starting calibration.
