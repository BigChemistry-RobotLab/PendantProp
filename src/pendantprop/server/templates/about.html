PendantProp

About

What is PendantProp?

PendantProp is an automated system for measuring surface tension using the pendant drop method. It integrates with Opentrons liquid handling robots to enable high-throughput characterization of surfactants and formulations.

Features

  • Automated pendant drop formation and imaging
  • Real-time surface tension analysis
  • Dynamic surface tension measurements
  • Integration with Opentrons OT-2 robot
  • Environmental monitoring (temperature, pressure, humidity)
  • Web-based interface for experiment control

Measurement Workflow

  1. Initialize: Upload deck layout and configure experiment
  2. Calibrate: Measure scale factor using water droplet (optional but recommended)
  3. Measure: Upload sample information and start measurements
  4. Analyze: View real-time results and plots

Calibration

Camera calibration determines the scale factor (mm/pixel) by measuring a water droplet of known surface tension. This ensures accurate surface tension measurements for your samples.

  • When to calibrate: Before each experiment session or when changing camera/lighting setup
  • Requirements: Pure, distilled water at room temperature
  • Process: Forms a pendant water droplet, analyzes geometry, calculates scale
  • Duration: ~60 seconds
  • Result: Update the scale parameter in settings with the measured value
