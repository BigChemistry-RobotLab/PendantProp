Protocol Initialization

Initialize the PendantProp protocol by providing an experiment tag and uploading your deck layout configuration. This will:

  • Load and validate the deck layout
  • Initialize the robot connection and pipettes
  • Set up containers and labware positions
  • Create output directories for data and results
  • Home the robot and pick up the initial tip
A unique identifier for this experiment. Will be used for output folder naming.
Upload the deck layout configuration file (see config/layouts/layout.csv for example)

Layout File Requirements:

  • No duplicates: Each container name and labware position must be unique
  • Multiple items: Use numbered naming like "sample plate, 1" and "sample plate, 2"
  • Columns required: container, labware, position, sample ID (optional)
  • Positions: Must match Opentrons deck positions (1-11 for OT2)

Before initializing: Ensure the robot deck is set up according to your layout file and all labware is properly positioned.
